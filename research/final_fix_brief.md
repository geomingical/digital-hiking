# 任務：「數位登山」(/workspace/digital-hiking) 最終美感修正（Codex + 我的審核）
先閱讀 research/codex_final_review.md（17 項）與 screenshots/final/*.png（d-* 桌機 1440x900、m-* 手機 390x844，可用 Read 看圖）。不要動 data 的題目事實與答案、不要改 research/ 內檔案、不要部署。請依序完成下列修正（沒列到的不要動）：

P0
1. 手機換裝頁 `.meter-why`（風險說明）不得單行省略，A/C 的「這份配裝符合本趟評分項目。0 分不代表登山沒有風險」要完整顯示（可換行），多條原因可換行或「查看其餘 N 項」展開；不縮字硬塞，並維持預覽/選項仍有足夠高度。
2. 手機題卡：保命徽章列旁加一行固定的簡短題名（題目 title），讓作答後捲到解說時仍知道在答哪題；作答後保留可捲回看選項（不要被固定區吃掉太多高度，固定區總高 ≤ 56px）。

P1
3. 換裝預覽（js/gear-art.js drawTorso 等）：中層厚度要在外觀上看得出——羽絨=外套輪廓/袖子明顯較蓬、領口/下襬露出羽絨色；刷毛=中等；不穿=最薄。使 A（刷毛+雨衣）與 C（羽絨+雨衣）的角色一眼不同。預覽下方加一行小字摘要「內層／中層／外層／鞋」文字（例：棉T・羽絨・防水外套・登山鞋）。
4. 預覽角色的下半身（褲子、鞋）要看得清楚：桌機版目前背包物品盤蓋住角色腿部——請把物品盤移到不遮角色的位置（例如預覽框內右側或下方獨立一列，必要時加高預覽框），確保牛仔褲、短褲、快乾褲、登山鞋、運動鞋/涼鞋都能辨識；牛仔褲要畫成完整長褲輪廓與藍色褲縫，鞋款名稱（資料 name）與畫出的鞋型一致。物品盤的圖示依「照明導航/補給/緊急備援」分組或加短標籤，至少 hover/tap 顯示名稱（手機用點擊）。
5. 手機換裝：帽子、內層等短選項改兩欄、每個點擊區≥44px，預覽捲動後可收成小摘要（若實作風險高，至少縮小預覽高度並維持分頁置頂）。
6. 字級：桌機 `.gear-opt-teach`、`.check-text` 與選山卡的內文提升到 14px 以上、行高 1.5（選項名稱 15–16px），版面不溢出；次要來源 12px 以上。
7. 所有可捲動清單（換裝、裝備檢查、結局回顧、題卡）加底部 padding/scroll-padding-bottom 與底部淡出漸層提示「下面還有」，不要讓半張卡被硬切。
8. 手機選山：`.mtn-chip.on` 改為淡底+底線代表「瀏覽中」，只有真正按了「選這座山」的卡片才顯示勾與「已選」；停用的「下一步」降低底色與陰影，旁邊用文字寫明欠缺什麼（例如「請先選山並勾選閱讀」）；勾選區整行可點（≥44px）。
9. 保命色彩減負：`.key-strip` 去掉一層巢狀邊框，`.fb-key` 改左側珊瑚色單線，粗體只用在必做行動；結局的「需複習」改淺紅底深紅字（文字+圖示，不只靠顏色）。
10. 手機走路畫面：靠近事件時只留一個主要入口（右下主鈕改標「查看狀況」），中央「前方有狀況，點這裡查看」提示在玩家完成第一次互動後收起（用 localStorage 或 state），揮手/喝水/拍照不要擋住搖桿與角色前方視野。
11. 次要文字對比：底部安全說明、桌機走路指引、季節頁補充文字改深褐色（約 #6b5c50，不用 opacity 降低）；桌機走路指引加奶油色實底短條。底部安全說明字級桌機≥12px。
12. 桌機開始畫面右側 NPC 被畫面邊緣切到：移入安全邊距或整體調整，避免人物只剩一半。

P2（時間允許）
13. 選山卡 banner 依山而異：七星=草坡、合歡=高山草原、加里=森林、玉山=裸岩+稜線、雪山=針葉林/圈谷、南湖=高山草原+雪季，季節少量雲/雨/植被色變化（沿用現有 canvas 扁平畫風）。
14. 墨鏡不要完全遮住眼睛（保留眼睛亮點或半透明鏡片）。

另（內容一致性）：部分題的情境文字直接寫玩家有特定裝備（例如 key-wait-warm-visible 的「你有乾衣、睡墊、頭燈…」），沒帶的玩家會對不上。請比照 headlamp 題的「顯示變體」機制，依玩家實際裝備改寫成中性或對應說法（只改顯示文字，不改事實、答案、風險、JSON 原文）。
